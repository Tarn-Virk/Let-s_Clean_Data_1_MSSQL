# 01_raw  -  evidence, never edited

Put the original files here (for Olist: `archive.zip` and the unzipped `archive/` folder).

* Keep the original zip untouched. If anything ever goes wrong you can start again from it.
* Open CSVs only in VS Code with read-only on. Never open and save them in Excel.
* This folder is ignored by Git (see `.gitignore`): raw data is large and often not yours to publish.
* SQL Server needs **Read** permission here (see `docs/phase-03-bronze.md`, section "Permissions").
